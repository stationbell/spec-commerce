# Demo artifacts

The customer's documents for the demo. Authored for this project, realistic in form, fictional in
project. They name no manufacturer or model.

- `spec-10-44-00-excerpt.md`: Part 2 of Section 10 44 00, Fire Extinguishers and Cabinets. 2.2 is the
  cabinet, 2.3 is the clean-agent extinguisher with its acceptable alternates. The page reads this
  text directly; `src/demo/requirements.ts` loads it and is what the demo button uses.
- `schedule-a-601.md`: the extinguisher schedule, which is where quantities come from. Specifications
  do not carry quantities.
- `code-citations.md`: code values and citations only, no reproduced code text.

For the video, open each file in a browser and print to PDF.
